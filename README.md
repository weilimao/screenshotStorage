# 📸 截图智能暂存箱 (Screenshot Storage Box)

[![Platform](https://img.shields.io/badge/Platform-Windows%20%7C%20macOS-blue)](#)
[![License](https://img.shields.io/badge/License-ISC-green)](#)
[![Node](https://img.shields.io/badge/Node.js-%3E%3D%2018.0.0-brightgreen)](#)

这是一个专为开发者和 AI 智能体使用者设计的跨平台（Windows & macOS）截图暂存与路径中转工具。

## 💡 它解决了什么痛点？

在使用 AI 智能体 CLI 终端（如各种大模型 CLI 交互工具）进行结对编程时，我们常常需要向 CLI 提供当前的报错或 UI 截图。然而，**绝大多数 CLI 命令行终端是不支持直接粘贴图片的**。

本工具通过在后台监听剪贴板和微信截图文件夹，自动将截图保存为本地 PNG 文件，并提供了一个始终置顶的极简悬浮窗。你可以：
1. **一键复制绝对路径**: 直接粘贴给 CLI 终端。
2. **原生拖拽中转**: 用鼠标直接把小浮窗里的图片**拖拽进任何 CLI 命令行终端**，终端会自动将该图片的绝对路径以文本形式输入！

## ✨ 核心特性

- 📥 **智能双源监听**:
  - **剪贴板监听**: 每隔 800ms 自动轮询剪贴板，秒级捕捉系统或微信截图（微信截图完成后默认自动入剪贴板）。
  - **目录深度监听**: 基于 `chokidar` 监听指定的本地截图目录（例如微信“保存”截图的文件夹），实现文件写入即落盘。
- 🔮 **记忆折叠小浮窗**:
  - **240px 黄金宽度**: 采用极致舒适的横向左右布局卡片（左侧缩略图支持拖拽，右侧显示时间与复制动作）。
  - **状态自动折叠**: 默认以折叠状态启动（高 145px，仅显 1 条最新截图），点击箭头一键拉伸展开（高 345px，显最近 3 条滚动列表）。
  - **断点记忆**: 自动记忆上一次浮窗的开关状态，下次重新启动软件时无感自动恢复。
- 🔍 **跨窗口联动大图预览 (Lightbox)**:
  - 暂存区主面板内置了基于磨砂玻璃（Glassmorphism）效果的大图预览，支持双击缩略图或点击预览键弹出，并支持 ESC / 点击空白处关闭。
  - 在小浮窗点击预览或双击时，主进程会**自动唤醒后台的主控制面板**（自动恢复最小化并置顶焦点），在主面板优雅地弹出大图，保障应用交互的一体化。
- 🗑️ **智能存储与清理策略**:
  - **超限清理**: 最多本地暂存最近的 100 张截图，超出后自动删除最旧的历史。
  - **过期清理**: 本地截图仅保留两周（14天），过期全自动销毁。
  - **手动清空**: 支持一键清空全部历史缓存。

## 🛠️ 技术架构

项目追求 **“高内聚、低耦合”** 的工程美学：
- **解耦原则**: 核心逻辑通过 `interface` 定义协议，实现与调用彻底解耦。
- **依赖注入**: 核心组件（配置、存储、窗口、监听）在主入口统一实例化，通过构造函数注入依赖，杜绝内部 `new` 依赖项。
- **IPC 消息路由**: 通过规范的 IPC 事件总线传递状态，实现跨窗口及主-渲染进程间的事件解耦。

## 🚀 运行与本地开发

### 1. 克隆并安装依赖

确保本地已安装 [Node.js](https://nodejs.org/)。

```bash
# 安装依赖 (包括 Electron, TypeScript, Chokidar, electron-builder 等)
npm install
```

### 2. 编译 TypeScript 代码

应用使用 tsc 将 `src/` 下的主进程与渲染进程 TS 代码编译至 `dist/`。

```bash
# 一次性编译
npm run build

# 或是开启热重载监听编译
npm run watch
```

### 3. 运行开发模式

运行以下命令，会自动编译并启动 Electron 应用：

```bash
npm run dev
```

## 📦 跨平台打包发布

项目已预装并配置好 `electron-builder` 打包引擎。您只需要在对应平台执行打包脚本，即可快速构建独立的安装包：

### 1. 一键打包

```bash
# 自动编译并打包为当前系统的安装格式
npm run dist
```

### 2. 构建产物
- 打包输出目录默认为项目根目录下的 **`dist-package/`**。
- **Windows**: 会在输出目录下生成 `截图智能暂存箱 Setup x.x.x.exe` 绿色安装程序及解压即用的 `win-unpacked` 绿色包。
- **macOS**: 会在输出目录下生成 `截图智能暂存箱-x.x.x.dmg` 圆角安装镜像。

### 3. 注意事项 (macOS 沙盒)
在 macOS 平台分发时，如果在沙盒机制 (App Sandbox) 下运行，拖拽文件传递给非沙盒应用（如某些第三方终端）可能受限。建议以**非沙盒包**或提供“辅助特权声明”的形式分发。
